# qa_python

## Тесты BooksCollector

В проекте реализованы тесты для проверки методов класса `BooksCollector`:

1. `add_new_book` — проверка добавления двух книг.
2. `add_new_book` — проверка добавления книги без жанра.
3. `set_book_genre` — проверка установки жанра книги.
4. `get_book_genre` — проверка получения жанра книги.
5. `get_books_with_specific_genre` — проверка получения книг определённого жанра с использованием параметризации.
6. `get_books_genre` — проверка получения словаря книг и жанров.
7. `get_books_for_children` — проверка списка книг, подходящих для детей.
8. `add_book_in_favorites` — проверка добавления книги в избранное.
9. `delete_book_from_favorites` — проверка удаления книги из избранного.
10. `get_list_of_favorites_books` — проверка получения списка избранных книг.
